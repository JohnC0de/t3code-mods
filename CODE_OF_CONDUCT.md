# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and welcoming. Disagree about ideas, not people.
- No harassment, insults, or personal or political attacks.
- No publishing of other people's private information.
- Accept helpful feedback, and give it with care.

## Report a problem

Report unacceptable behavior to the maintainer through a
[private security advisory](https://github.com/JohnC0de/t3code-mods/security/advisories/new)
(it reaches only the maintainers) or by email to the address on the maintainer's GitHub
profile. All reports are reviewed, and the reporter's privacy is respected.

Maintainers can remove comments, commits, code, issues and other contributions that break
this code, and can ban contributors who break it.
