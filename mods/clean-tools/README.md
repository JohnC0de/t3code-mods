# Clean tool rows

Makes the chat timeline easier to scan:

- Commands show in monospace.
- Thinking rows are dimmed.
- Failed tool calls are red.
- Icons and chevrons fade until you hover the row.

## Options

Settings > Mods > Clean tool rows:

- **Hide thinking rows**: hides thinking lines between tool calls. Inside a tool list they fade.
- **Hide tool icons**: text only, aligned to the left.

CSS and UI code only. Changes apply live, with no reload.
